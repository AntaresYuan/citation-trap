# CLAUDE.md — Citation Trap

A mesocosm benchmark: an LLM agent answers multi-hop questions and must cite a
supporting passage for every claim. Scored on a 2×2 of **citation faithfulness**
(primary) × **answer correctness**. See `README.md` for the full overview and
results; `LOCAL_DEV.md` for the mesocosm local-dev loop.

## Environments (two, on purpose)

- `.venv` — **Python 3.9**. Everything except mesocosm: `env.py`, `agent/`,
  `serve.py`, tests. Deps: `rank_bm25`, `pytest`.
- `.venv311` — **Python 3.11**. mesocosm only (`swecc-mesocosm` requires ≥3.11).
  Used for `auxiliary/` + the `mesocosm` CLI.

## Commands

```bash
# core (.venv)
python scripts/build_data.py            # rebuild data/ from HotpotQA (N_QUESTIONS)
python -m pytest -q                     # tests — keep green
python -m agent.driver --agent scripted # offline fixture, all 4 quadrants
python -m agent.driver --agent deepseek --judge --concurrency 8   # real run
#   flags: --model <registry name> --qid <id> --limit <n> --concurrency <n>
python serve.py                         # dashboard + in-browser live runs (judge on)

# mesocosm (.venv311)
mesocosm validate auxiliary/benchanything.json
python auxiliary/adapter.py --port 8765   # serves /health /reset /step /close
mesocosm env submit --solo --name "Citation Trap" --github-url <repo>
```

`DEEPSEEK_API_KEY` must be set for real runs / the judge (it's the user's key —
never commit it). Model registry lives in `agent/deepseek_agent.py` (`MODELS`).

- Code, comments, docs, GitHub: English. (Chat with the user: Chinese.)

  are generated by the driver but committed (so the static dashboard works).

## Scoring rules (don't regress these)

- **Opaque passage ids** (`p_<sha1>`). Never go back to `q1_supp_1`/`q1_dist_2`
  naming — it leaks which passages are gold.
- **Correctness is lenient**: EM OR gold-span-in-answer OR F1≥0.7 (raw EM/F1 still
  reported). Pure EM is too strict for a free-form agent.
- **`unsupported` (a claim with no citation) is a coverage note, NOT a trust
  failure.** Faithfulness = faithful / citations-actually-made; trustworthy = no
  fabricated AND no misattributed AND ≥1 faithful.
- Faithfulness has two backends: the **gold-set proxy** (default, offline) and
  the **entailment judge** (`--judge`; `serve.py` on by default, `CT_JUDGE=0`
  off). The judge decides faithful-vs-misattributed by real support, not gold
  membership; each score carries `scored_by`.

## mesocosm gotchas

- The platform's `BindingVow` schema is **stricter than local `mesocosm validate`**:
  `reward.type` must be `scalar` (not `continuous`); `techniques` must be objects,
  not strings. Local validate passing does NOT guarantee the platform accepts it.
- Member JWT expires fast — re-login (`mesocosm auth login`) on a 401.
- No CLI for env detail; GET `https://api.swecc.org/bench/v1/developer/environments/{env_id}`
  with `mesocosm auth token` to read `status` / `error_message`.
- `auxiliary/env.py` loads the repo-root `env.py` core via importlib under a
  distinct name to avoid the module-name collision (both are `env`).
